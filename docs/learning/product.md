# 产品经理学习路径

**目标：** 能描述用户问题，理解基础技术约束，与研发共同定义验收标准。

## 阶段一：建立共同语言

1. [API 是什么](/start/api)：了解客户端与服务端如何通信。
2. [HTTP 请求与响应](/start/http)：分清常见方法和错误类型。
3. [AI 基础概念](/ai/)：理解 LLM、Agent 和 MCP。
4. [提示词怎么写](/ai/prompt)：向 AI 清晰表达任务。

## 阶段二：需求与协作

下一批将建设用户问题识别、需求结构化、PRD、原型验证和需求评审。内容完成前，先结合实际需求练习下面的任务。

## 实战练习

选一个不含敏感数据的业务流程，写出：

- 用户是谁，遇到了什么问题。
- 希望改变什么结果。
- 哪些条件必须满足。
- 用什么可观察行为验收。

**完成标准：** 开发人员无需猜测关键业务规则，就能复述该需求的核心目标和限制。
