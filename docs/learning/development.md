## 实战练习

设计并实现一个任务查询接口，至少覆盖正常返回、错误参数和无权限请求。

**完成标准：** 提交的 PR 说明修改内容，附带真实执行的验证结果。未运行的测试明确标注。

后续会根据团队真实技术栈补充语言、框架与数据库专项课程。
