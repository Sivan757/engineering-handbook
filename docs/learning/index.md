# 产研学习路径

**知识按主题归档，学习按照角色和目标组织。** 不同岗位可以共享同一篇基础文章。

| 路径 | 适合谁 | 目标 |
| --- | --- | --- |
| [产品经理](/learning/product) | 产品、交互与业务分析 | 从问题发现走向可验证的需求 |
| [研发工程师](/learning/development) | 前端、后端、实习开发者 | 从理解接口到完成受审查的功能 |
| [测试与质量](/learning/quality) | 测试、研发 | 从定义预期到验证交付 |
| [AI 实践](/learning/ai) | 产品、研发、测试 | 从提示词使用到可靠的 AI 工作流 |

## 全员共同基础

1. [API 是什么](/start/api)：理解软件如何协作。
2. [第一次调用 API](/start/first-api-call)：完成可观察的实际操作。
3. [如何编写提示词](/ai/prompt)：把模糊任务转换为清晰要求。
4. [AI 安全与边界](/ai/security)：识别不应该发送到外部工具的信息。

以上不是强制考核顺序。具备相关经验的读者可以直接进入专业路线。
