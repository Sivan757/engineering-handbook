# 发布与回滚

**目标：** 明确发布内容、审批人、验证方式及恢复路径。

本文是建议流程。实际发布遵守既有审批、网络安全和变更管理要求。

```text
完成需求 → PR 审核 → CI 检测 → 测试环境验证
→ 发布审批 → 生产部署 → 冒烟测试 → 监控
                                ↘ 异常时回滚
```

## 发布前

- 核对版本、提交、变更内容与负责人。
- 明确配置、数据库迁移、依赖顺序。
- 准备回滚步骤、监控指标和告警。
- 提前对接域名、证书与网络放行。

## 发布后

检查关键功能、错误率和延迟。发现异常时根据回滚条件决定是否恢复旧版本。

练习：给一个新查询接口设计三条冒烟测试和一个回滚条件。
