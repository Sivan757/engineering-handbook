# HTTP 请求与响应

HTTP 是客户端与服务器交换消息的一套协议。

## 一个 POST 请求

```http
POST /api/tasks HTTP/1.1
Host: example.test
Content-Type: application/json

{"title":"学习 API"}
```

## 常用方法

| 方法 | 用途 |
| --- | --- |
| GET | 读取 |
| POST | 创建或触发操作 |
| PUT | 整体替换 |
| PATCH | 部分修改 |
| DELETE | 删除 |

## 常见状态码

| 状态码 | 含义 | 先做什么 |
| --- | --- | --- |
| 200 | 成功 | 看返回数据 |
| 201 | 创建成功 | 查资源标识 |
| 400 | 请求不合法 | 核对参数 |
| 401 | 身份未认证 | 核对登录与 token |
| 403 | 无权限 | 核对角色和授权 |
| 404 | 路径或资源不存在 | 核对 URL |
| 429 | 被限流 | 查看重试策略 |
| 500 | 服务端错误 | 根据请求 ID 查日志 |

## 排错练习

访问 `https://httpbin.org/status/401`，解释 401 与 403 的区别。
