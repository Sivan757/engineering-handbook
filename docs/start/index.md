# 通识基础与新人入门

**目标：** 能理解 API、HTTP 和软件协作的基础概念，并实际完成一次接口调用与排错。

## 推荐入门顺序

| 顺序 | 内容 | 学完能做什么 |
| --- | --- | --- |
| 1 | [API 是什么](/start/api) | 解释前后端通信 |
| 2 | [第一次调用 API](/start/first-api-call) | 用 curl 发送请求 |
| 3 | [HTTP 请求与响应](/start/http) | 识别方法、参数与状态码 |
| 4 | [如何排查 API 错误](/start/troubleshoot-api) | 有条理地描述和定位失败 |
| 5 | [提示词怎么写](/ai/prompt) | 把模糊任务变成可验证要求 |

## 不同读者怎么用

- **产品经理：** 重点理解接口与产品交互的关系。
- **研发工程师：** 重点掌握调试、异常和真实接口实现。
- **测试人员：** 重点掌握输入条件与预期输出。

同一基础知识可以进入不同岗位的学习路径，参阅 [产研学习路径](/learning/)。

## 开始练习

~~~bash
curl -i 'https://httpbin.org/get?topic=api'
~~~

先观察返回的 HTTP 状态码，再阅读 [第一次调用 API](/start/first-api-call)。
