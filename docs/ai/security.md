# AI 安全与边界

**先判断数据能否离开当前环境，再调用外部 AI 服务。**

## 不要提交到外部 AI

- API Key、JWT、数据库密码和私钥。
- 真实个人信息、客户数据和生产日志。
- 未获批准外发的源码、合同和内部架构。
- 内部域名、网络拓扑与访问凭据。

## 常见风险

| 风险 | 应对 |
| --- | --- |
| 幻觉 | 查询官方文档、运行验证 |
| 提示词注入 | 区分不可信资料和可靠指令，限制工具权限 |
| 数据泄露 | 脱敏、审批、使用合规环境 |
| 供应链风险 | 检查依赖来源、许可证和漏洞 |

## 实际操作

1. 给工具配置最小权限。
2. 对外部网页和工具结果保持警惕。
3. 重要写操作由人工批准。
4. 在测试环境验证后再发布。

练习：给出安全分析生产问题的替代方案，而不是上传完整生产日志。
