# AI 编程工作流

**原则：** AI 辅助生成方案与代码，工程师对需求、验证和提交负责。

```text
明确需求与验收标准
  ↓
阅读代码、确定修改边界
  ↓
AI 提供方案与风险
  ↓
小范围实现
  ↓
运行测试与静态检查
  ↓
人工审查差异
  ↓
提交 PR
```

## 示例提示词

```text
为当前任务列表 API 增加状态筛选。
保持已有接口兼容。
只修改 Controller、Service 和相关测试。
先检查现有代码并提出修改计划。
完成后列出受影响文件、验证命令和未解决风险。
未实际执行的测试不要标为通过。
```

## 交付前

- 阅读全部代码差异。
- 运行项目要求的测试与构建。
- 审核鉴权、输入边界和异常处理。
- 不让 AI 绕过评审或直接修改生产环境。
- 在 PR 中区分“已验证”和“未验证”。

**练习：** 让 AI 生成三个测试用例，人工核对断言后运行。
