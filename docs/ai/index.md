# AI 基础概念

**一句话：** 大语言模型（LLM）根据上下文生成输出，但输出不等于正确性证明。

| 概念 | 简单解释 |
| --- | --- |
| 模型 | 使用训练参数处理、生成内容的系统 |
| Prompt | 给模型的任务说明 |
| Token | 模型处理文本的片段单位 |
| 上下文窗口 | 一次推理能使用的信息范围 |
| Tool Use | 模型请求外部工具执行操作 |
| RAG | 检索资料后辅助模型生成答案 |
| Agent | 围绕目标规划并调用工具的系统 |
| MCP | 连接 AI 应用、工具与数据的协议 |

模型可能编造不存在的 API、参数或文献，需要核对来源并执行验证。
