# AI 通识与实践

**最终目标：** 读者能够解释常见 AI 概念，把工作任务转成有效输入，正确使用 AI 工具，并验证结果是否可靠。

本课程服务于产品经理、开发与测试。它不要求一开始就会编程，但所有读者都需要完成实践练习。

## 学习目标与验收

| 阶段 | 学习重点 | 学完能够做什么 | 验收方式 |
| --- | --- | --- | --- |
| 1. 建立认知 | AI、LLM、Token、上下文、局限 | 解释模型做了什么、哪些内容必须核实 | 用自己的话讲解模型回答的来源和不确定性 |
| 2. 会用 AI | Prompt、结构化输出、多轮任务 | 将一个模糊工作任务写成明确要求 | 用同一需求进行两次改写并比较结果 |
| 3. 理解集成 | 模型 API、RAG、Tool、Agent、MCP、Skills | 画出一次 AI 系统调用与数据流 | 正确区分六种技术的职责 |
| 4. 可靠交付 | 产品场景、AI 编程、评估、安全 | 验证输出、控制权限、形成可复用成果 | 完成综合案例与验收清单 |

建议每次阅读一个小节后就完成练习。只阅读、不练习，不算完成。

## 按岗位学习

- **产品与设计：** 完成阶段 1、2、4 中的产品实践，再理解阶段 3 的概念。
- **研发：** 完成四阶段，重点实践模型 API、工具调用与 AI 编程。
- **测试：** 完成阶段 1、2、4，重点学习结构化输出、评估和测试设计。

## 学习方法

1. 先读结论和一个案例。
2. 遇到新术语，打开 [术语表](/reference/glossary)。
3. 完成一个练习并记录结果。
4. 用自己的话解释“为什么这样做”。
5. 若实际结果与文章不同，在 GitHub 提交问题。

本课程是**第一版教学材料**。示例以公开、脱敏数据为主，技术实现还需核对目标服务和 SDK 的具体版本。
