# 大语言模型是如何工作的？

**一句话：** 大语言模型（LLM）通过训练学习大量模式，推理时根据当前上下文生成后续 Token，逐步形成回答。

## 先看一个例子

~~~text
用户：写一个任务列表 API 的设计提纲。
模型：1. 定义资源路径
     2. 约定请求参数
     3. 明确响应结构
     4. 定义权限与错误处理
~~~

模型不一定访问了你的项目。它通常在已有训练模式和当前输入的基础上组织答案。

## 从输入到输出

~~~text
自然语言输入
  ↓ 转换为 Token
上下文与指令
  ↓ 模型运算，计算下一 Token 的概率
选取/生成 Token
  ↓ 重复
形成一段回复
~~~

这是帮助初学者理解的简化过程，并未展示模型内部所有计算。现代模型的训练还可能包含指令微调、偏好优化等阶段。

### 训练和推理不同

- **训练（Training）：** 根据大量数据更新模型参数。
- **推理（Inference）：** 使用已有参数处理当前输入，生成结果。

给模型发一条消息，通常不会立刻修改它的模型参数。具体产品如何使用对话数据，需查看相应服务的数据政策。

### 为什么“按 Token 预测”还能写代码？

程序语言包含稳定的语法、结构与问题模式。模型可以从训练中形成对代码结构的预测能力。

但它不自动知道你项目最新的 API、依赖版本或生产状态。

## 容易混淆的三个概念

| 概念 | 不是 |
| --- | --- |
| 训练数据 | 可逐条搜索的实时数据库 |
| 上下文 | 模型永久记住的全部事实 |
| 生成回答 | 已被实际执行并通过验证的结果 |

## 练习

让模型解释你正在学习的一段脱敏 JSON，随后指出回答中的哪些部分来自输入，哪些部分是模型的额外假设。

**完成标准：** 能说出至少两条需要核实的断言。
