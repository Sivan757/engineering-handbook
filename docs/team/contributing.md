# 文档贡献指南

**原则：** 一个 PR 解决一个明确问题，优先改进真实有人问过的内容。

## 添加文章

1. 搜索现有文档，避免重复。
2. 使用 [文档模板](/reference/templates)。
3. 提供一个脱敏且可复现的示例。
4. 修改 `docs/.vitepress/config.mts` 导航。
5. 运行 `npm run docs:build`，提交 PR。

## 推荐结构

一句话定义、使用场景、示例、常见错误、练习和参考资料。

## 内容状态

- **入门资料**：概念解释。
- **建议稿**：等待团队评审。
- **已采纳**：团队确认的约定。
- **废弃**：保留迁移说明。

禁止公开凭据、个人数据、生产地址和未经批准的内部资料。
