# 团队协作与知识共享

**目标：** 让知识可搜索、可验证、可复用，而不是依赖个人记忆。

## 建设原则

1. 收集实际问题，优先解决重复出现的知识盲区。
2. 按领域维护文章，按角色组织学习路径。
3. 通过 GitHub Issue 收集问题，通过 PR 审核文档。
4. 为重要流程留下可重复执行的操作步骤。
5. 将“个人建议”与“团队已采纳的规范”严格区分。
