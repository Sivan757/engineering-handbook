# 团队成长与知识共享

**目标：** 知识可以被搜索、复现和改进，而不是只靠某个人记忆。

## 三个机制

1. 每周收集高频问题，优先回答重复问题。
2. 每周进行一次 15 分钟的短分享，附真实例子。
3. 每次分享留下 Markdown 文档、步骤和自检题。

## 文档类型

| 类型 | 内容 |
| --- | --- |
| 入门教程 | 概念、原因、操作 |
| 工作手册 | 条件、操作步骤、异常处理 |
| 设计决策 | 背景、备选方案、取舍和影响 |

不把“这个很简单”当作解释。鼓励新人先说明自己的理解，再讨论差异。
