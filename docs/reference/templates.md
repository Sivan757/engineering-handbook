# 文档模板

**先判断读者要完成什么，再选择模板。**

| 类型 | 使用场景 | 仓库模板 |
| --- | --- | --- |
| Tutorial 教程 | 从零学习并完成具体任务 | `templates/tutorial.md` |
| How-to 操作指南 | 解决正在发生的问题 | `templates/how-to.md` |
| Reference 参考 | 快速查询准确字段、配置或状态 | `templates/reference.md` |
| Explanation 原理解释 | 理解机制、限制和技术取舍 | `templates/explanation.md` |

模板位于仓库根目录，完整文件可从 [GitHub templates](https://github.com/Sivan757/engineering-handbook/tree/main/templates) 复制。

## 编辑规则

- 使用中文标题和清晰段落。
- 首次出现术语时给出简短解释。
- 给出脱敏、可复现的例子。
- 标明适用版本和权威资料。
- 若是建议流程，明确标注“建议稿”。

阅读 [详细写作规范](/team/writing-guide)，或使用仓库的 AI 写作与审核 Skills。
