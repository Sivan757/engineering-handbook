# 文档模板

复制后填写：

````md
# 主题名称

> 状态：入门资料 / 建议稿 / 已采纳

**一句话：** 用简短语言解释概念。

## 什么时候会用到？

给出真实且脱敏的使用场景。

## 怎么做？

说明步骤，必要时提供可运行命令。

```bash
# 示例命令
```

## 常见错误

说明表现、原因与解决方法。

## 练习与自检

提供能够检验理解的练习。

## 参考资料

列出权威链接和适用版本。
````

## 写作要求

- 先解释术语，再使用缩写。
- 提供具体示例。
- 不包含生产凭据、内部地址和客户数据。
- 规范类文档标明范围、状态和例外。
