# 术语表

| 术语 | 含义 |
| --- | --- |
| API | 软件之间的调用约定 |
| HTTP | 传递请求与响应的网络协议 |
| JSON | 结构化文本数据格式 |
| REST | 围绕资源组织接口的架构风格 |
| SDK | 封装服务调用的工具包 |
| Token | 表示会话或权限的凭据；AI 场景也指文本片段 |
| OAuth 2.0 | 授权框架 |
| OIDC | 基于 OAuth 2.0 的身份认证协议 |
| LLM | 大语言模型 |
| Prompt | 给模型的任务说明与上下文 |
| RAG | 检索外部资料辅助回答 |
| Agent | 规划任务并调用工具的系统 |
| MCP | 连接 AI 应用与工具、数据的协议 |
| Git | 分布式版本控制工具 |
| PR | 提交审核并合并变更的请求 |
| CI | 持续集成 |
| CD | 持续交付或部署 |
| Trace | 请求经过多个服务时的调用记录 |
| 幂等 | 重复执行不会产生额外预期外效果 |

遇到不理解的术语，可创建知识点 Issue。
