# Repository writing instructions

This repository is a public Chinese knowledge base for product, engineering, quality, and AI practitioners.

## Editorial workflow

1. Read `docs/team/writing-guide.md` before writing.
2. Identify the primary reader, their task, and the Diátaxis document type.
3. Use the matching template under `templates/`.
4. Write one document around one clear reader goal.
5. Explain unfamiliar terms and include practical examples.
6. Mark proposals as draft proposals. Never imply they are adopted company policy.
7. Do not invent commands, sources, test outcomes, or product capabilities.
8. Never publish confidential company details, credentials, internal URLs, or personal data.
9. Run `npm run docs:build` and review every changed link before submitting a PR.
10. Prefer editing existing relevant content over duplicating a topic.

## Skills

- `.agents/skills/engineering-doc-writer/SKILL.md`: plan and draft articles.
- `.agents/skills/engineering-doc-reviewer/SKILL.md`: review factual quality, readability, and publication readiness.
